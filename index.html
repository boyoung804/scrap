오늘의 주요기사 자동분류

기사 이미지를 올리면 AI가 내용을 읽고 원하는 구분으로 분류해 보고서를 만듭니다.

1. 프로필

프로필 추가·편집
구분 이름만 적으면 AI가 기사 내용을 읽고 알맞은 구분에 넣습니다. 기사가 없는 구분도 소제목은 표시됩니다. 이름에 '오피니언'이 있으면 사설·칼럼이 그곳에 모입니다. 단, 기관 이름이 직접 나온 기사는 사설·칼럼이어도 「기관 관련 보도」에 들어갑니다.
처음 한 번만: 무료 Gemini 키 연결 ·
기사 이미지를 읽는 AI로 Google Gemini를 씁니다. Google 계정으로 무료 키를 한 번 만들어 붙여넣으면, 그다음부터는 zip 파일만 올리면 됩니다.
1. aistudio.google.com/apikey에 Google 계정으로 로그인합니다.
2. 「API 키 만들기(Create API key)」를 누릅니다. 결제 수단 입력 화면이 나오면 멈추세요(무료로 쓰려는 경우 필요하지 않아야 합니다).
3. 키 목록 줄 오른쪽의 복사 아이콘(겹친 네모)으로 키를 복사해 아래에 붙여넣고 「저장」을 누르면 맞는 키인지 바로 확인합니다.
※ 이 파일은 PC에 저장한 뒤 더블클릭해서 크롬/엣지로 열어야 합니다. Claude 화면 안이나 게시된 링크에서는 구글 연결이 차단됩니다.
키는 비밀번호와 같습니다. 이 컴퓨터의 브라우저에만 저장되고 파일에는 들어 있지 않습니다. 기사 이미지는 분석을 위해 Google로 전송되며, 무료 이용분은 Google이 서비스 개선에 입력을 활용할 수 있으므로 내부 문서는 올리지 마세요.

2. 기사 이미지 올리기

기사별 이미지가 든 zip 파일과 기사 목록 엑셀(제목·URL)을 끌어다 놓거나 눌러서 선택
zip과 엑셀을 한꺼번에 선택해도 되고 따로 올려도 됩니다. 이미지는 파일 이름 순서대로 읽고, 엑셀의 URL은 파일명의 매체·제목으로 찾아 연결합니다.
수집된 관련 보도: 확인 중…
① 엑셀 제목만으로 분류합니다. 못 가린 기사는 「분류 미정」에 둡니다. ② ①을 한 뒤, 제목으로 못 가린 기사만 이미지(zip)를 읽어 다시 분류합니다(시간이 있을 때). 두 방법 모두 Gemini 키가 필요합니다. 관련 보도는 수집 파일에서 가져옵니다. 엑셀 기사가 수집된 관련 보도와 같은 기사이면 주요 이슈에 넣지 않고, 관련 보도의 「지면」 항목(엑셀의 제목·면수)으로 합칩니다.
분류가 안 될 때 원인을 화면에 그대로 보여줍니다 (이미지를 올린 뒤 누르세요)

선별 기준 보기
AI는 기사에서 사실만 읽어냅니다(기관과의 관련 정도, 논조, 면수, 지면 비중, 같은 이슈를 쓴 매체 수). 중요도는 아래 고정 점수표로 계산하므로 같은 기사는 항상 같은 점수가 나옵니다.
· 「기관 관련 보도」 범위: 기사에 기관 이름이나 약칭(예: 문체부)이 글자로 실제 나온 기사만 해당합니다. 기관장 직함이나 산하기관 이름만 나온 기사는 주요 이슈의 해당 구분으로 갑니다.
· 기관 관련 기사의 중심 +4 / 단순 언급 +2 / 기관명은 없어도 소관·산하·유관 분야 기사 +3
· 기관에 대한 부정 논조 +3 / 긍정 논조 +1
· 1~3면 게재 +2
· 지면 비중(제목 크기·기사 길이) 큼 +2 / 보통 +1 / 작음 0
· 점수가 같으면 올려주신 순서를 따릅니다
· 같은 이슈를 다룬 다른 매체 1곳당 +1 (최대 +3)
· 기관 관련 보도: 기관이 나온 기사 중 4점 이상 / 주요 이슈(구분별): 점수 높은 순으로 최대 N건
· 정렬: 같은 이슈를 다룬 기사끼리 이웃하게 묶어 보여주고, 묶음 순서는 그 묶음의 최고 점수 순입니다(전체본은 올린 순서).
· 제외된 기사는 2페이지에 모이고, 기사 왼쪽 체크박스로 골라 1·2페이지 사이를 옮기거나 구분을 바꿀 수 있습니다. 판독하지 못한 기사는 항상 포함됩니다.
